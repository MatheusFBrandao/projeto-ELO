# Projeto Simulado — Lume Studios | ELO Jr. 2026.2

Este repositório contém a solução do **Projeto Simulado** desenvolvido para a 3ª Fase do Processo Seletivo da **ELO Jr. Engenharias e Arquitetura** (Núcleo de Automação e TI — NATI).

O projeto consiste na concepção, estruturação, otimização e hospedagem de um **site institucional responsivo** para o escritório fictício **Lume Studios (Arquitetura e Urbanismo)**.

---

## 🌐 Link de Acesso ao Site
Acesse o site implantado e funcional via GitHub Pages:
**[https://matheusfbrandao.github.io/projeto-ELO/](https://matheusfbrandao.github.io/projeto-ELO/)**

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **CMS & Design System:** WordPress (Tema Astra & Gutenberg / Spectra Blocks)
- **Formulários Interativos:** Forminator
- **Exportação Estática:** Simply Static (Conversão do ambiente PHP/MySQL para site estático otimizado em HTML5, CSS3 e JS)
- **Hospedagem & CI/CD:** GitHub Pages
- **Versionamento:** Git & GitHub

---

## 📑 Estrutura das Seções do Site

1. **Hero Section:** Apresentação da marca, proposta de valor e Call to Action (CTA) para orçamento.
2. **Sobre Nós:** História, valores institucionais e posicionamento do escritório.
3. **Serviços:** Apresentação dos nichos de atuação (*Projetos Arquitetônicos, Design de Interiores, Paisagismo e Reformas*).
4. **Metodologia de Trabalho:** Etapas claras do processo de desenvolvimento de projetos (*Briefing, Estudo Preliminar, Anteprojeto e Projeto Executivo*).
5. **Portfólio / Projetos:** Galeria de projetos desenvolvidos.
6. **Depoimentos:** Validação social e experiência dos clientes.
7. **Contato:** Formulário funcional para captação de *leads* e solicitação de orçamentos.
8. **Rodapé:** Links de navegação, contatos oficiais, redes sociais e direitos autorais.
